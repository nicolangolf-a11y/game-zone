# GameZone

1. Node.js installieren: https://nodejs.org/
2. Supabase-Projekt erstellen: https://supabase.com/
3. `supabase.sql` im Supabase SQL Editor ausführen.
4. `.env.example` in `.env` umbenennen und URL + Anon Key eintragen.
5. Im Projektordner `npm install` und danach `npm run dev` ausführen.
